\begin{abstract}
Production machine learning (ML) systems exhibit silent failure modes under non-stationary streaming distributions where covariate shift and concept drift degrade predictive accuracy without triggering traditional HTTP or infrastructure-level exceptions. Existing Application Performance Monitoring (APM) tools are oblivious to statistical drift, while contemporary MLOps profiling frameworks operate primarily as offline, batch-oriented diagnostic utilities lacking causal topology awareness. This paper presents \textbf{ArgusML}, a lightweight, fully in-memory observability platform engineered upon five foundational data structures: (i) a fixed-capacity Circular FIFO Buffer for zero-allocation asynchronous ingestion ($O(1)$), (ii) a Double-Ended Sliding Window achieving $O(1)$ amortized rolling accuracy, precision, recall, and P99 latency evaluation, (iii) an in-memory Hash Map providing constant-time baseline distribution retrieval, (iv) a Binary Max-Heap priority queue for logarithmic incident severity triage ($O(\log N)$), and (v) a 4-layer dynamic Directed Acyclic Graph (DAG). ArgusML combines two-sample Kolmogorov-Smirnov hypothesis testing ($O(N \log N)$) and Population Stability Index (PSI) quantile binning ($O(N + B)$) with graph-theoretic Reverse-BFS ($O(V + E)$) to isolate upstream culprit feature corruption and compute a multi-factor Root Cause Confidence Score (RCS). Furthermore, it incorporates a closed-loop 4-step validation gate for automated zero-downtime model retraining and version promotion. Empirical evaluation across classification and regression benchmarks demonstrates that ArgusML imposes less than $0.45\text{ ms}$ telemetry compute latency per prediction, achieves 100\% precision in culprit feature attribution under controlled covariate injection, and successfully remediates degraded model accuracy from 68\% to 96\% in real time.
\end{abstract}

\section{Introduction}
Unlike classical deterministic software services that crash with runtime exceptions or explicit HTTP 500 error codes, deployed Machine Learning (ML) models fail \textbf{silently}~\cite{sculley2015}. An inference microservice serving predictions on customer churn, fraud detection, or financial risk can maintain perfect infrastructure metrics---such as $10\text{ ms}$ P99 latency, zero network dropouts, and nominal CPU consumption---while its predictive utility collapses due to non-stationary environments, statistical distribution shifts, and upstream ETL pipeline corruption~\cite{breck2019, shankar2022}.

In their landmark paper on machine learning technical debt, Sculley et al.~\cite{sculley2015} demonstrated that actual ML modeling code comprises less than 5\% of production systems, with the remainder dominated by ingestion, verification, serving, and monitoring. Despite this, production observability remains bifurcated between:
\begin{enumerate}
    \item \textbf{Infrastructure APMs:} Systems such as Prometheus and Datadog monitor hardware telemetry (CPU, RAM, network I/O, error codes). However, Breck et al.~\cite{breck2019} demonstrated that traditional APMs are mathematically blind to statistical data degradation.
    \item \textbf{Offline Batch Profilers:} Contemporary tools (e.g., Evidently AI~\cite{evidently}, Great Expectations~\cite{greatexp}, WhyLogs~\cite{whylogs}) compute statistical profiles over static batch datasets. However, they operate out-of-band, impose heavy computational footprints, and lack dynamic topological awareness of upstream data pipelines and downstream service consumers.
\end{enumerate}

To bridge this critical architectural divide, this paper introduces \textbf{ArgusML}, an ultra-lightweight, in-memory observability platform built upon five foundational Data Structures and Algorithms (DSA): Circular FIFO Queue, Double-Ended Sliding Window, Hash Map Baseline Store, Binary Max-Heap Priority Queue, and Dynamic 4-Layer Directed Acyclic Graph.

\section{Related Work \& Theoretical Foundations}

\subsection{Taxonomy of Distribution Shift}
In non-stationary streaming environments, the joint probability distribution $P(X, Y)$ of input feature space $X \in \mathbb{R}^d$ and target label space $Y \in \mathcal{Y}$ varies across time $t$~\cite{gama2014, shimodaira2000}. By Bayes' theorem:
\begin{equation}
P(X, Y) = P(X) \cdot P(Y \mid X) = P(Y) \cdot P(X \mid Y)
\end{equation}

\begin{itemize}
    \item \textbf{Covariate Shift (Feature Drift):} The marginal input distribution shifts while conditional class probabilities remain invariant~\cite{shimodaira2000, sugiyama2012}:
    \begin{equation}
    P_t(X) \neq P_{\text{baseline}}(X) \quad \text{while} \quad P_t(Y \mid X) = P_{\text{baseline}}(Y \mid X)
    \end{equation}
    \item \textbf{Concept Drift:} The posterior conditional probability distribution shifts over time~\cite{widmer1996, gama2014}:
    \begin{equation}
    P_t(Y \mid X) \neq P_{\text{baseline}}(Y \mid X) \quad \text{while} \quad P_t(X) = P_{\text{baseline}}(X)
    \end{equation}
    \item \textbf{Upstream Pipeline Corruption:} Schelter et al.~\cite{schelter2018} observed that data pipeline changes (e.g., unit conversions, default value alterations) corrupt input features without altering schema types.
\end{itemize}

\subsection{Statistical Distance Metrics}
\begin{enumerate}
    \item \textbf{Two-Sample Kolmogorov-Smirnov Test~\cite{massey1951}:} Quantifies maximum supremum divergence between empirical cumulative distribution functions $F_{\text{base}}(x)$ and $F_{\text{live}}(x)$:
    \begin{equation}
    D_{n, m} = \sup_{x \in \mathbb{R}} \left| F_{\text{base}}(x) - F_{\text{live}}(x) \right|
    \end{equation}
    If $p < 0.05$, the null hypothesis $H_0$ is rejected, confirming covariate shift ($O(N \log N)$).
    \item \textbf{Population Stability Index (PSI)~\cite{yurdakul2018}:} Discretizes baseline distributions into $B = 10$ quantile bins:
    \begin{equation}
    \text{PSI} = \sum_{b=1}^B (A_b - E_b) \cdot \ln\left( \frac{A_b + \epsilon}{E_b + \epsilon} \right)
    \end{equation}
    Standard thresholds: $\text{PSI} < 0.10$ (stable), $0.10 \le \text{PSI} < 0.25$ (moderate), $\text{PSI} \ge 0.25$ (critical shift) ($O(N+B)$).
\end{enumerate}

\section{ArgusML System Architecture}
ArgusML executes as an asynchronous, in-memory telemetry runtime organized into five distinct topological layers:
\begin{enumerate}
    \item \textbf{Layer 1 (Ingestion Buffer):} Circular FIFO \texttt{EventQueue} with modulo pointer arithmetic ($C = 5000$).
    \item \textbf{Layer 2 (Rolling Telemetry):} Double-ended \texttt{MetricSlidingWindow} maintaining running confusion matrix states ($W = 400$).
    \item \textbf{Layer 3 (Statistical Drift):} \texttt{DriftEngine} evaluating KS and PSI against \texttt{ModelRegistry} Hash Map baselines every 25 predictions.
    \item \textbf{Layer 4 (Topological RCA):} 4-layer dynamic \texttt{DependencyGraph} executing Reverse-BFS and Forward-BFS traversals.
    \item \textbf{Layer 5 (Priority Incident Triage):} \texttt{AlertMaxHeap} ranking active incidents and triggering closed-loop 4-step retraining.
\end{enumerate}

\section{Algorithmic Formulations \& Complexity Analysis}

\subsection{Asynchronous Ingestion \& Rolling Metrics ($O(1)$)}
To prevent blocking production model endpoints, \texttt{EventQueue} implements modular pointer arithmetic:
\begin{equation}
\text{tail}_{\text{next}} = (\text{tail} + 1) \pmod C, \quad \text{head}_{\text{next}} = (\text{head} + 1) \pmod C
\end{equation}
When the queue reaches capacity $C$, oldest unconsumed events are dropped gracefully in $O(1)$ time.

\texttt{MetricSlidingWindow} maintains rolling true/false positive counts ($TP, FP, TN, FN$). When sliding window $W$ is saturated, the oldest element is evicted in $O(1)$:
\begin{equation}
\text{Accuracy}_t = \frac{TP + TN}{TP + FP + TN + FN} \implies O(1) \text{ amortized}
\end{equation}

\subsection{Dynamic 4-Layer DAG \& Reverse-BFS Attribution ($O(V+E)$)}
The production topology is modeled as a Directed Acyclic Graph $G = (V, E)$ across four categorical layers:
\begin{equation}
\mathcal{L}_1: \text{Pipelines} \to \mathcal{L}_2: \text{Features} \to \mathcal{L}_3: \text{Model} \to \mathcal{L}_4: \text{Services}
\end{equation}

\begin{itemize}
    \item \textbf{Reverse-BFS Upstream Attribution:} Traverses reverse adjacency list $E_{\text{rev}}$ starting from degraded model node $u_{\text{model}} \in \mathcal{L}_3$ upstream to isolate candidate culprit feature nodes $v \in \mathcal{L}_2$ and originating ingestion pipelines in $O(V + E)$ time.
    \item \textbf{Forward-BFS Downstream Blast Radius:} Traverses forward adjacency list $E_{\text{fwd}}$ downstream from $u_{\text{model}}$ into $\mathcal{L}_4$ to identify impacted microservices in $O(V + E)$ time.
\end{itemize}

\subsection{Multi-Factor Root Cause Confidence Scoring (RCS)}
ArgusML computes a composite Root Cause Confidence Score ($\text{RCS}$):
\begin{equation}
\text{RCS}(f) = w_1 \mathcal{S}_{\text{drift}}(f) + w_2 \mathcal{S}_{\text{perf}} + w_3 \mathcal{S}_{\text{topo}}(f) + w_4 \mathcal{S}_{\text{blast}}
\end{equation}
where $w_1 = 0.45, w_2 = 0.30, w_3 = 0.15, w_4 = 0.10$. The feature maximizing $\text{RCS}(f)$ is isolated as the primary culprit.

\subsection{Binary Max-Heap \& Closed-Loop Retraining Gate}
\texttt{AlertMaxHeap} maintains incidents in an array backed by custom \texttt{\_sift\_up} and \texttt{\_sift\_down} pointer swaps ($O(\log N)$ push/pop).

The Closed-Loop Retraining Gate enforces a 4-step validation gate:
\begin{equation}
\text{Acc}(\mathcal{M}_{\text{cand}}) \ge \text{SLA}_{\text{acc}} \land P99 \le \text{SLA}_{\text{lat}} \land \text{Acc}_{\text{cand}} > \text{Acc}_{\text{active}} \land R^2 \ge 0
\end{equation}
Upon passing, candidate $\mathcal{M}_{\text{cand}}$ is promoted to production with zero downtime ($v1.0.0 \to v1.1.0$).

\section{Experimental Evaluation}

\subsection{Experimental Setup}
Evaluation was conducted on standard benchmarks: (1) \textbf{Telecom Churn} ($N=7043$, $d=20$), (2) \textbf{Credit Card Fraud} ($N=10000$, $d=14$), and (3) \textbf{California Housing} ($N=20640$, $d=8$).

\subsection{Latency Overhead Benchmarks}

Synchronous telemetry adds only \textbf{$17.0\ \mu\text{s}$} ($<0.02\text{ ms}$) overhead per live prediction. Complete background drift check and DAG traversal execute in under \textbf{$0.45\text{ ms}$}.

\subsection{Drift Attribution \& Automated Recovery}
Under controlled covariate injection ($\mu_{\text{shift}} \ge 2.0\times$), Reverse-BFS correctly identified the culprit feature in \textbf{100\%} of runs with $\text{RCS} \ge 0.86$. Automated retraining successfully restored model accuracy from 68.1\% back to 96.2\% with zero production downtime. All 17 Pytest unit tests passed with 100\% success rate.

\section{Conclusion}
This paper presented ArgusML, an in-memory graph-powered observability platform engineered upon five foundational data structures. By unifying microsecond ingestion ($O(1)$), non-parametric statistical hypothesis testing, Reverse-BFS topological root cause attribution ($O(V+E)$), and binary max-heap priority triage ($O(\log N)$), ArgusML provides continuous automated observability and closed-loop self-healing for production machine learning systems.
